# 교육공무직 320일 근무 편성 도우미(Ver2.0)

- 상시근로자는 (일반) 시트 하나로 생성합니다.
- 방중비 근로자는 (매크로적용)·(일반) 두 시트로 생성합니다.
- 비동의자 모드와 별도의 산정기준, 공휴일 5개년 조회·저장·오프라인 사용을 지원합니다.
- 학년도 옆에 자료 반영 범위와 작성 가능 여부를 표시합니다.
- 실제 Microsoft Excel 검사를 포함해 211개 검사를 통과했습니다.

실행 파일 하나를 다운로드해 실행하면 됩니다. 기존 버전을 사용 중이면 새 실행 파일로 교체합니다.
파일 버전: 2.0.0.0
